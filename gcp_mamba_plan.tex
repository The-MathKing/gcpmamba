\section{Introduction}
The development, verification, and submission pipeline for \textbf{GCP-Mamba (Graph-Conditioned Perturbation Mamba)} is structured to satisfy the zero-hallucination, rigorous benchmark validation, and reproducibility protocols required for an Original Paper submission to Oxford's \textit{Bioinformatics}. This project focuses on the combinatorial problem of gene perturbations and addresses the computational scaling limits of Transformers by utilizing a bidirectional Mamba backbone, conditioning its internal parameters directly on graph structures.

\section{Phase 1: Environment Architecture \& Dependency Management}
\textbf{Timeline:} Days 1--3 \\
\textbf{Objective:} Establish a deterministic, reproducible execution environment to eliminate hardware-level variance.

\begin{itemize}
    \item \textbf{Container Isolation:} Initialize a Docker container using a base image optimized for deep learning stack stability (e.g., \texttt{nvidia/cuda:12.4.1-devel-ubuntu22.04}).
    \item \textbf{Compiler Verification:} Ensure \texttt{nvcc} is exposed to the environment path to allow runtime compilation of Mamba's custom Triton/CUDA kernels.
    \item \textbf{Dependency Sequencing:} Install core packages strictly in the following sequence to prevent library symbol conflicts:
    \begin{itemize}
        \item PyTorch (Stable release compatible with CUDA 12.x)
        \item PyTorch Geometric (\texttt{torch-geometric}) for graph processing layers.
        \item \texttt{causal-conv1d} (Core Mamba sequence convolution dependency).
        \item \texttt{mamba-ssm} (Standard selective state-space implementation layers).
    \end{itemize}
\end{itemize}

\section{Phase 2: Data Acquisition \& Preprocessing Pipeline}
\textbf{Timeline:} Days 4--8 \\
\textbf{Objective:} Extract, clean, and format the golden standard benchmarks without technical or biological data leakage.

\subsection{Source Material Procurement}
\begin{itemize}
    \item \textbf{Perturbation Data:} Download the Norman et al. (2019) K562 single-cell dataset directly via the programmatic API provided in the \texttt{gears} library package or the Hugging Face hub (\texttt{matthewshu/gears-norman}).
    \item \textbf{Knowledge Graph Topology:} Extract the Human Gene Ontology (GO) graph structure using the biological network generation scripts present in the \texttt{GEARS} framework.
\end{itemize}

\subsection{Standardization \& Multi-Split Engineering}
\begin{itemize}
    \item Filter raw transcript count matrices down to the top \textbf{5,045 highly variable genes} defined in the standard benchmarking protocol.
    \item Normalize expression data via total count scaling per cell followed by a $\ln(\text{counts per million} + 1)$ transform.
    \item Enforce strict, non-overlapping dataset partitions across three experimental conditions to validate model generalization capacity:
\end{itemize}

\section{Phase 3: Algorithmic Engineering \& Core Architecture Development}
\textbf{Timeline:} Days 9--17 \\
\textbf{Objective:} Replace standard multi-layer decoders with a bidirectional Mamba backbone, conditioning its internal parameters directly on graph structures.

\subsection{Structural Modality Construction}
\begin{itemize}
    \item Map the baseline single-cell expression vector to a continuous latent space using an embedding layer.
    \item Compute the full pair-wise shortest-path distance matrix $\mathbf{D}$ for all 5,045 genes within the Gene Ontology network topology.
\end{itemize}

\subsection{Graph Conditioning of SSM Equations}
Modify the discretization layer inside the Mamba framework. Instead of treating the step size parameter $\Delta$ as a purely data-driven sequence variable, scale the parameters based on the network proximity of genes:

\begin{equation}
\Delta_{\text{graph}} = \Delta \odot \sigma(\mathbf{W}_g \mathbf{D})
\end{equation}

\begin{equation}
\mathbf{A}_{\text{graph}} = \mathbf{A} \odot \exp(-\gamma \mathbf{D})
\end{equation}

\textit{Where $\sigma$ represents a Sigmoid activation gating, $\mathbf{W}_g$ is a learnable parameter weight matrix, and $\gamma$ acts as a structural decay constant.} This formulation ensures that when the state-space scan passes sequentially across highly linked biological pathways, the system retains context heavily, preventing long-range memory degradation across related functional gene groups.

\section{Phase 4: Rigorous Benchmarking \& Verification Strategy}
\textbf{Timeline:} Days 18--24 \\
\textbf{Objective:} Conduct direct performance validation against active state-of-the-art computational baselines.

\subsection{Execution Optimization}
\begin{itemize}
    \item Train the model utilizing an AdamW optimizer with a linear learning rate scheduler featuring warmup steps.
    \item Implement cross-entropy loss coupled with mean squared error metrics focused strictly on the top 20 genes responding most aggressively to the specific perturbation.
\end{itemize}

\subsection{Statistical Baselining}
Run identical datasets through the local implementations of \textbf{GEARS}, \textbf{scGPT} (fine-tuned for cellular perturbation prediction tasks), and \textbf{AttentionPert}. Ensure all comparative systems share identical cross-validation splits.

\section{Phase 5: Biological Interpretation \& Explainability Audit}
\textbf{Timeline:} Days 25--28 \\
\textbf{Objective:} Transition statistical validation patterns into interpretable biological insights to satisfy editorial requirements.

\subsection{Latent State Extraction}
\begin{itemize}
    \item Extract the magnitude patterns of the dynamic selection parameter $\mathbf{B}$ and step size parameter $\Delta$ across varying perturbation runs.
    \item Map these internal state parameters back to specific biological entities to chart exactly how hidden information flows between pathways during synthetic knockouts.
\end{itemize}

\subsection{Epistatic Interaction Identification}
\begin{itemize}
    \item Identify instances where predicted gene expression states display non-additive behavior (e.g., buffering or strong synergy).
    \item Plot these predicted profiles against true wet-lab test validation data to confirm that the model's performance improvements stem directly from accurately learning real biological mechanisms rather than simply minimizing training set loss metrics.
\end{itemize}

\section{Phase 6: Publication Preparation \& Submission Protocols}
\textbf{Timeline:} Days 29--30 \\
\textbf{Objective:} Package the developed tool according to the formal manuscript standards of Oxford's \textit{Bioinformatics}.

\end{itemize}
